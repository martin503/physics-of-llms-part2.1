Physics of Language Models part 2.1 reproduction

Does a language model know variable dependencies in math problems before it is asked anything? We trained a custom GPT-2 model and V-probe on iGSM problems to extract what the model knows about the problem structure from its activations. dep(A, B) asks “does variable A depend on B?”, for one pair of variables.

Every problem below is drawn as its dependency graph: variables are nodes, each tested pair an arrow A → B, styled by the true answer and coloured by the probe's prediction. The same probe trained for a random-init model acts as the control to verify probe training added little capability. We also show the trained model's generated solutions.
